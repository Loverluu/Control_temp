    # Control_temp

Programa en Python para controlar temperatura.
    ## Qué hace

- Lee temperatura
- Detecta temperatura alta
- Muestra alarma
- Detecta errores

    ## Reglas

- Más de 80°C = alarma
- 80°C o menos = normal
- Negativo = error

    ## Ejecutar

python main.py

    ## Tests

pytest
